1. Ingresar como cliente, reservar un turno de «Consulta clínica general» (o usar uno existente).
2. `recepcion@vitalia.uy` / `Vitalia2026!`: Agenda del día → registrar llegada.
3. `ferreira@vitalia.uy`: Mi agenda → iniciar atención → completar motivo y diagnóstico → firmar. El mensaje dice que el cargo quedó pendiente de cobro.
4. Recepción → Panel → **Cobros**: aparece el cargo ($ 1.200). Cobrar $ 500 en efectivo → «Pago parcial», saldo $ 700. Probar $ 800 (error: supera el saldo) y transferencia sin número (error). Cobrar $ 700 por transferencia con n.º de operación → «Pagado».
5. «Ver» un comprobante → se imprime. Como cliente, `/cuenta` → «Mis cargos y comprobantes».
6. `admin@vitalia.uy` → Cobros → **Anular** un comprobante (sin motivo: error). Con motivo: aparece la nota de crédito, el comprobante figura «Anulado» y el cargo recupera el saldo; Recepción puede cobrarlo otra vez.
