## Cómo probarlo

1. F5 → crear una cuenta y verificarla (o ingresar con una existente).
2. Barra superior → **Mi cuenta**. Ver los datos y el texto «Lo ven: …» debajo de cada uno.
3. **Editar mis datos** → borrar el nombre o poner teléfono `12` → «Guardar cambios»: aparecen los mensajes en rojo y no se guarda.
4. Poner datos válidos → «Guardar cambios»: cartel verde y la barra muestra el nombre nuevo.
5. Con animales y turnos cargados: ver «Mis animales» (botón Historia clínica) y el próximo turno.
6. Servicios usados: con la cuenta del veterinario, finalizar una consulta de un turno de este cliente (misma pestaña, ver bitácora del 9/11); volver como cliente → aparece el servicio con «Reservar de nuevo».
