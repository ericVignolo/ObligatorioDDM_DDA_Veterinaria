# Ramas git

`main` (versión integrada) ← `desktop` (sección A, activa) → `desktop-mobile` (B) → `desktop-mobile-api` (C).

- **Una rama por sesión** `<nombre>/sesion-AAAA-MM-DD` desde `desktop`, con un solo PR al final (DT-ORG-06).
- Quien trabajó prueba con F5 y mezcla su propio PR (DT-ORG-05).
- `main` se actualiza desde `desktop` en cada hito estable.
