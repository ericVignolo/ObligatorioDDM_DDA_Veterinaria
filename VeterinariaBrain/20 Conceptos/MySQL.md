# MySQL

Base de datos de la sección C (DT-BD-01). Versión 8.4 LTS; agenda protegida con `SELECT … FOR UPDATE` (DT-BD-02). **Proveedor de EF Core en revisión, lo decide [[Diego]]**: Pomelo solo soporta EF Core 9 (sin soporte desde el 2026-11-10); el docente usa `MySql.EntityFrameworkCore` de Oracle con EF Core 10.

Solo la [[API ASP.NET Core]] se conecta a la base: guarda los datos y sus restricciones (correo único, microchip único). Las reglas y los permisos están en la API.

Parte de [[Mapa Arquitectura]].
